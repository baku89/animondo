# Fonts

## BBB Sprat

- Files: `BBBSprat-Regular.otf` (400), `BBBSprat-Regularlight.otf` (300)
- Design: Sprat by Ethan Nakache (Collletttivo); non-binary glyphs added by
  Eugénie Bidaut & Julie Patard of the Bye Bye Binary collective
- Source: https://typotheque.genderfluid.space/fr/fontes/bbb-sprat
- License: SIL Open Font License (OFL), per the typothèque page above.
  Bye Bye Binary also publishes the CUTE usage conditions (credit +
  means-based donation): https://genderfluid.space/documents/2024_BBB_CUTE_FR.pdf

A-OTF Ryumin Pr6N is served via Adobe Fonts (Typekit kit `akx2ghp`,
configured in `nuxt.config.ts`) and is not stored in this repository.
